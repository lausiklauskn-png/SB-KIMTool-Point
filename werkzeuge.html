Die Werkbank — Module in drei Stufen

Schicht 2 · Werkzeugkiste (herunterladen)

Drei Stufen. Jede Kachel trägt Doppel-Status (Sage / Point) und eine Erklärung. „Schlummert" = vorgebaut, springt bei Bedarf an — nicht leer.

Worum geht's? SBKIM ist eine Art Partnervermittlung für kleine Web-Apps: Sie lernen sich kennen, verstehen sich über ihre Bedeutung (nicht nur über Stichworte) und docken aneinander an — ganz ohne zentralen Server.

Die Kacheln unten sind die Bausteine dafür. Module mit dem grünen Knopf „⧉ Code kopieren / ⬇ Datei laden" sind echt und 1:1 aus dem getesteten Sage-Protokoll übernommen — du kannst sie direkt in deine eigene App einbauen. Manche brauchen Internet (z. B. das Verstehen von Texten oder der Handschlag zwischen zwei Apps); das steht ehrlich an der jeweiligen Kachel.

Werkstatt — Werkzeuge wirklich prüfen

Erster echter Schritt Richtung Live-Modell: Klick lädt die echten Module und lässt sie eine kleine Selbst-Prüfung rechnen. Hier laufen die offline-Werkzeuge (04 Match, 16 Siegel) — was grün wird, rechnet wirklich.

Live-Match — zwei Profile vergleichen

Zwei „das kann ich / das suche ich"-Texte → Embedding (03) → Match (04). Der echte semantische Vergleich läuft in deinem Browser, sobald das Sprachmodell geladen ist; sonst ein klar markierter Demo-Vergleich (zählt gemeinsame Wörter).

Protokoll-Lauf — die ganze Kette auf einmal

Erstmals greifen die Bausteine als Kette ineinander: Identität (02) → Passung (03+04) → bei Treffer Vertrauen prüfen (02) → Siegel-Stand (16). Jeder Schritt zeigt ehrlich, ob er hier rechnet oder erst in deinem Browser läuft.
